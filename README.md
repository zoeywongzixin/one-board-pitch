## The problem

At FCSIT, class cancellations, room changes and deadline updates arrive through **WhatsApp, Spectrum, email and Instagram**. A typical student is in more than ten course and OCC groups.

| | What happens today |
|---|---|
| **01** | Announcements are scattered across 4+ platforms |
| **02** | Students miss cancellations and room changes, and walk to empty classrooms |
| **03** | Announcements never update the student's timetable |
| **04** | Lecturers post the same notice several times |
| **05** | Old messages are hard to find |

## The idea

One Board connects every announcement to the student's own schedule.

```diff
- WED 10:00   WIA2006   DK1
+ WED 10:00   WIA2006   CANCELLED
```

When a lecturer cancels a class, changes a room or extends a deadline, every affected student's **timetable and calendar update automatically**.

> Spectrum stores announcements. **One Board puts them in your day.**

## Objectives

1. One platform for all course and OCC announcements
2. Timetables that update automatically when classes change
3. Deadlines that sync to students' calendars
4. Notifications only when a change affects you
5. Lecturers post once and reach every affected student
6. A searchable archive of past announcements

## Scope

| Student | Lecturer | Admin |
|---|---|---|
| View live timetable | Post announcements | Manage courses & users |
| Deadline calendar | Cancel / reschedule / change room | Faculty-wide notices |
| Search announcements | Set & extend deadlines | |

**Platform:** web app (responsive, mobile-friendly) · FCSIT only

**Out of scope:** integration with Spectrum, MAYA, WhatsApp or UM email · course registration · assignment submission · chat or forums

## Presentation controls

The slides are a single HTML page and need no installation.

| Key | Action |
|---|---|
| `→` `Space` / click | Next slide or build |
| `←` | Previous |
| `N` | Toggle speaker notes |
| `T` | Start / reset the 3:00 timer |
| `F` | Fullscreen |
| `Ctrl` + `P` | Export slides as PDF |

To run locally, open `index.html` in any browser.
