Announcements that update your timetable. A 3-minute pitch deck by SyncWave Solutions (UMisOne · OCC 1).

**Live:** https://<username>.github.io/<repo>/

The whole deck is one `index.html` file. Open it straight in a browser, or view it on GitHub Pages.

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| → · Space · PageDown · click | Next slide |
| ← · PageUp | Previous slide |
| Swipe left / right (phone) | Next / previous slide |
| Home / End | First / last slide |
| F | Toggle fullscreen |
| N | Show / hide speaker notes |
| T | Start the 3:00 timer; press again to reset it (turns red under 0:15) |
| Ctrl + P | Print or save as PDF, one slide per page, notes hidden |

The address ends in `#1` to `#6`, so a refresh keeps you on the same slide.

For the PDF: in Chrome or Edge's print dialog choose **Save as PDF**, set Margins to **None** and tick **Background graphics**.
